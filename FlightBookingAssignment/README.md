Flight Booking System

This project is a complete backend service for searching and booking flights, built using Spring Boot and MySQL. It supports the full booking flow: searching flights, selecting seats, adding passenger details, generating PNRs, viewing booking history, and canceling tickets before the 24-hour cutoff. The system also manages seat availability automatically and includes safeguards like seat-format checks, duplicate-seat prevention, and passenger validation.

The project emphasizes practical backend design with a clean layered structure, centralized error handling, and strong validation, ensuring predictable responses and reliable behavior. It also includes unit tests for key features, making the system maintainable and ready for real-world use.
